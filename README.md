### AI-Powered Security Operations Center Platform

**Real-time threat detection · GPT-4o AI triage · SIEM ingestion · Incident response · MITRE ATT&CK mapping**

## ✨ 8 Modules

| Module | What it does |
|--------|-------------|
| 🚨 **Alert Queue** | Real-time alerts, severity triage, MITRE mapping, AI analysis |
| 🤖 **AI Analyst** | GPT-4o threat analysis, IOC extraction, KQL/SPL generation |
| 📋 **Incident Command** | Full lifecycle, analyst assignment, SLA tracking |
| 🧠 **Threat Intel** | IOC database, threat actor attribution, TLP classification |
| 🏢 **Asset Registry** | Risk scoring, criticality index, vulnerability correlation |
| 🗺️ **MITRE Coverage** | Live ATT&CK heat map, detection gap analysis |
| 📚 **Playbooks** | Pre-built + AI-generated response runbooks |
| 📊 **SIEM** | REST API log ingestion, correlation, streaming |

## 🚀 Quick Start

```bash
git clone https://github.com/anshul2414/sentinel-soc.git
cd sentinel-soc
pip install -r requirements.txt
# Optional: export OPENAI_API_KEY=sk-...
python app.py
# → http://localhost:5000
```

## 🐳 Docker

```bash
docker-compose up -d
# → http://localhost:8080
```

## 🤖 AI Integration

Set `OPENAI_API_KEY` for live GPT-4o. Demo mode works without it — 15 seeded alerts, 8 assets, 8 IOCs, 4 playbooks included.
